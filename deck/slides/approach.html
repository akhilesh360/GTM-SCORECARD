Approach

One pipeline from raw exports to a board-ready scorecard

1
Raw exports
Leads, deals, spend, calls, touchpoints
2
Normalize
Aliases and definitions from one standard file
3
HubSpot
Free CRM as system of record
4
Attribution model
First, last and linear touch; CAC, ROAS, LTV, payback
5
AI lead agent
Scores, routes and tasks every new lead
6
Dashboard
Filter by company, channel, month
Portable by design: adding a company means a data folder and one config file with its pipeline names. No code changes.
Everything runs on free tools: HubSpot free CRM, Google Sheets and Looker Studio. The only paid piece is the DeepSeek API key that powers agent scoring. Portability was tested by adding a throwaway third company from config alone.
